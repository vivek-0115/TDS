# Tools in Data Science (TDS)

A repository documenting my learning journey through the **Tools in Data Science (TDS)** course. It contains week-wise practice exercises, graded assignment solutions, projects, and experiments completed throughout the course.

## Course Overview

The course covers the complete modern data science workflow, including:

* Development Environment & Tooling
* Deployment & API Engineering
* LLM Engineering
* Retrieval-Augmented Generation (RAG)
* Agentic AI
* Web Scraping & Data Processing
* CI/CD, Security & Cloud
* MLOps & Fine-Tuning
